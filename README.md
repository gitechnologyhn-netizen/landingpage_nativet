# NATIVET Landing Page

Landing page estática en español para la empresa agropecuaria NATIVET. Incluye secciones de hero, acerca de, servicios, impacto, diferenciales, casos de éxito, preguntas frecuentes y formulario de contacto, con estilos responsivos en `styles.css`.

## Estructura
- `index.html`: marcado principal de la landing page.
- `styles.css`: hoja de estilos con tipografías, rejillas y componentes de tarjetas/botones.

## Ejecutar localmente
1. Clona este repositorio.
2. Inicia un servidor estático desde la raíz del proyecto:
   ```bash
   python -m http.server 8000
   ```
3. Abre `http://localhost:8000` en tu navegador.

## Notas
- Fuentes cargadas desde Google Fonts (`Inter` y `Playfair Display`).
- Estilos optimizados para pantallas móviles y de escritorio.
